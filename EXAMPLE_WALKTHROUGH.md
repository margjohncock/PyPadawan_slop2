This is the content target for the maintained `examples/csv_analysis` project.
Statements are labelled Documented, Observed in source or Not established.

1. **Purpose:** Quote the README's group-comparison purpose and method. Link to the README lines and the module's documentation.
2. **Data:** Show the documented observation layout and millimetre units; show the local CSV header `group,value`. Separate observed column/key accesses from documented requirements.
3. **Reading route:** Start with `analysis.py`, named in the documented run command. Show its main guard, then the `main` and `summarise` definitions with navigable evidence.
4. **Processing:** Show reading CSV, removing missing values, grouping, averaging and writing CSV with the relevant source. Identify method-name matches as clues rather than proven types. Explain the custom function from its own documentation.
5. **Run:** Explain the current project folder, Python version, separate environment and pip requirements route. Quote the documented run command. Offer terminal-specific environment instructions without running them.
6. **Success:** Quote the reference means A=3.0 and B=8.0. Separately show the observed CSV-writing call. Do not claim the upload was run or the means verified by PyPadawan.
7. **Settings:** Show `--input`, `--output`, their literal defaults and help text. Show the function's output-path default and usage locations.

the treatment comparison is appropriate for a different research study.
